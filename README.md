Esse aplicativo foi criado para auxiliar futuros projetos de matrix de LED realizados por alunos de SDM, é gratuito, e permito que seja 
feita alterações para servir qualquer função extra ou para qualquer alteração no código de leitura das imagens para a matrix no código em C.

Para usar basta selecionar o arquivo da sua imagem atráves do botão de navegar arquivos, e então extraia a informação dos pixeis, os quais
já estarão formatados para colocar no código, no formato que fizemos o Jogo da memória (EM C).

Evite tentar extrair informação de pixel da imagem placeholder, sua resolução é alta e causa problemas na interface, congelando o aplicativo, isso se aplica a qualquer imagem de alta resolução, limite-se a imagens menores que 1000x1000 pixels.
